# Release Notes

## 0.1.0 - Milestone 1

- Added native Expo iPhone app shell for Studio Log.
- Added SQLite-backed offline records.
- Added local photo capture/import, compression, and attachment support.
- Added dashboard, inventory, recipes, projects, kiln, gallery, and studio OS modules.
- Added backup export/import with photo data.
- Added Codemagic/TestFlight build path.
- Added custom development build support; Expo Go is not a target.

Known limitations:

- Local-only data, no cloud sync yet.
- JSON backup can become large with many photos.
- Pricing calculators, recipe versioning, kiln shelf/post tracking, and social calendar workflows are scheduled for milestone 2.
